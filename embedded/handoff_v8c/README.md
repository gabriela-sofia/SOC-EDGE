# Handoff V8C de Bancada

Este diretório prepara a estrutura pública para o próximo experimento V8C.

O V8C ainda não está executado neste repositório. A estrutura existe para orientar aquisição real ou semi-real em bancada e retorno auditável dos resultados.

## Conteúdo

```text
templates/   modelos de log e relatório
manifests/   registro de arquivos esperados
```

## Escopo

- aquisição contínua;
- sensor real;
- bateria real ou setup semi-real controlado;
- logs com timestamps;
- registro de V/T/I reais;
- SOC inferido;
- heap, latência, resets e estabilidade.

## Limites

Não usar esta estrutura para afirmar campo, produção ou validação industrial.
