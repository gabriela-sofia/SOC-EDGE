# Visão Geral do Handoff ESP32

O handoff ESP32 é o pacote técnico usado para executar e auditar a validação embarcada. Ele não é apenas um envio operacional; faz parte da rastreabilidade metodológica do projeto.

O pacote público curado está em:

```text
embedded/handoff_v8b2/
```

Ele contém firmware, headers, replay vectors, cenários de anomalia, script de validação, manifests e template de resultados.
