# Escopo de Claims do Handoff

O handoff V8B2 permite afirmar apenas que o pacote foi validado por replay embarcado na ESP32, quando os logs e o validador sustentam PASS.

Ele não permite afirmar:

- validação em campo;
- produção;
- validação de sensor físico real;
- operação contínua longa;
- robustez completa a falhas reais de hardware.
