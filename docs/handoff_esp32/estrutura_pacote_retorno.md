# Estrutura do Pacote de Retorno

O retorno da execução deve conter:

```text
results/
  serial_logs/
  validation_outputs/
  hardware_report.md
  result_report.md
  notes.md
```

Arquivos brutos de log podem ficar fora do Git se forem longos. O relatório público deve preservar métricas, comandos e critérios de interpretação.
