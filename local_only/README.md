# Materiais Locais

Esta pasta documenta materiais que podem existir no workspace, mas não devem ser versionados.

Exemplos:

- dados brutos;
- zips de datasets;
- outputs massivos;
- caches;
- logs longos;
- modelos binários;
- handoffs brutos não curados;
- arquivos de configuração de ferramentas locais.

Esses materiais podem ser usados para auditoria e reprodução local, mas a versão pública deve conter apenas documentação, manifests, código versionável e exemplos pequenos.
